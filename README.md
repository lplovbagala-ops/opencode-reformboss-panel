# ReformBoss Panel 1.2

Небольшая панель OpenCode Desktop с моделями ReformBoss: статус, провайдер, логотип, задержка и аптайм последней пробы. Два вида — список (строка на модель, шеврон раскрывает подробности) и сетка карточек; кнопка `▦`/`☰` в шапке переключает вид, выбор запоминается.

## Установка

```powershell
git clone https://github.com/lplovbagala-ops/opencode-reformboss-panel "$env:USERPROFILE\.config\opencode\plugins\reformboss-panel"
```

Затем добавьте путь к папке в глобальный `~/.config/opencode/opencode.json`:

```json
{
  "plugins": ["C:/Users/<вы>/.config/opencode/plugins/reformboss-panel"]
}
```

Перезапустите OpenCode Desktop — панель появится слева снизу. Дальше `⚙` → «Войти».

Требуется OpenCode Desktop 2.3.0 (GUI API). `index.js` — no-op, Desktop сам загружает `./gui-experimental` из пакета. Отключить: убрать запись из `plugins` или выключить GUI в Extensions → Plugins.

Предупреждение: плагин — персональная автоматизация консоли ReformBoss через вашу сессию. Используйте на свой риск и в рамках правил сервиса.

Кнопка-шестерёнка `⚙` открывает настройки: фильтр по состоянию (Все / Работают / Перебои / Не работают / Без проб), поиск по названию модели, «Обновить», «Войти» и сохранение ключей. Фильтры запоминаются, активный фильтр подсвечивает шестерёнку зелёным, в строке состояния видно «показано N из M». Вход в ReformBoss (Telegram) живёт в настройках, отдельной кнопки в шапке больше нет.

Размер панели фиксирован: ширина 320 px, высота по содержимому с ограничением по окну (список прокручивается внутри). Позиция по умолчанию — левый нижний угол. В настройках `⚙` есть галочка «Фиксировать позицию»: включена — панель стоит на месте; выключена — её можно перетащить за шапку, место запоминается. Растягивания нет; сворачивание кнопкой «−» в шапку и разворот «+».

Иконки провайдеров вшиты в `gui-experimental.cjs` как инлайн-SVG (Simple Icons, CC0) — панель не тянет картинки из сети. Для Zhipu (GLM), xAI (Grok), Agnes и общего каталога значка в наборе нет — там квадрат с буквой в цвете провайдера.

При первом запуске нажмите `⚙` → «Войти» и подтвердите вход Telegram на настоящем сайте ReformBoss. Данные появятся автоматически. Авторизация сохраняется в отдельном профиле Electron `persist:reformboss-panel-v2`. Плагин читает https://reformboss.com/pricing (каталог с рангами), /console/api/me (свой ранг) и /api/status.json (публичные пробы: `lab`, `state`, `latency_ms`, `uptime_1h`, `uptime_24h`). Браузер Codex имеет другую сессию: его вход не переносится.

Сайт не сообщает параллельный лимит запросов: плагин не изображает его известным. При ошибках вместо нулей показывает отсутствие данных. Распределитель запросов не включается.

OpenCode не предоставляет отдельный слот левой колонки. Плагин использует официальный `window.bottom` и держит панель в левом нижнем углу (`position:fixed`). Перетаскивание включается только при снятой галочке «Фиксировать позицию» в настройках; позиция — `reformboss-panel-position-v3`, состояние фиксатора — `reformboss-panel-pin-v1`.

Для загрузки пакет должен быть указан каталогом в глобальном `opencode.json`, поле `plugins`. Desktop сам подхватывает `./gui-experimental` из пакета; `index.js` — no-op. Реализация требует GUI API OpenCode Desktop 2.3.0. Для отключения уберите запись пакета или отключите его GUI в настройках Extensions → Plugins.
